# Appearances Tiff SMP: The Ultimate Experience
## A custom feature-mod tailored for the Appearances Tiff SMP (A.T. SMP)

This mod compiles everything added to the A.T. SMP, bringing unique mechanics, powerful endgame gear, and custom audio features to your world.

---

## New Resource: Meteorite

Meteorite is a rare, powerful resource found in the overworld at meteor crash sites. It surpasses Netherite in strength and durability.

*   **How to Obtain:** Mine the raw ore, smelt it in a furnace, and then cool the hot ingot by dropping it into water.
*   **Gear Specs:** Tools feature **3,452 durability**, faster mining speeds, and higher attack damage.
*   **Armor Specs:** Features a **45x durability factor** (Helmet: 11x45, Chestplate: 16x45, Leggings: 15x45, Boots: 13x45).
*   **Crafting:** Meteorite gear must be upgraded in a **Smithing Table** using a *Meteorite Upgrade Smithing Template* and one *Meteorite Ingot*.

### Special Tool: The Meteorite Bedrock Pickaxe
A specialized tool designed to break Bedrock blocks.
*   **Purpose:** Allows safe access to the Nether roof without using glitch-exploits, or can be used strategically for void traps.
*   **Limitations:** It has only **16 durability** and cannot mine any other block blocks.
*   **Recipe:** Crafted like a standard pickaxe using 3 Meteorite Ingots and 2 sticks.

## Custom Music Discs

Bring your own soundtrack into Minecraft! The mod includes a built-in **MP3-to-Music-Disc Converter** that handles audio formatting automatically:
*   Converts **MP3 (Stereo or Mono)** directly into **OGG (Mono)** format for optimal in-game performance.
*   ⚠️ **Important Note:** This mod *does not* include a music downloader. All MP3 files must already be stored locally on your hard drive.
